# 1. Validación y clasificación de datos

Se solicita un programa que lea **N números (definido por el usuario)** y determine:

* cantidad de positivos, negativos y ceros
* promedio de los positivos
* el número de mayor valor

---

# 2. Análisis de cadena

Dada una cadena ingresada por el usuario:

* contar cuántas vocales tiene
* contar cuántos espacios
* invertir la cadena
* determinar si es palíndromo

---

# 3. Gestión de calificaciones

Se deben ingresar los datos de **N estudiantes**:

* nombre
* nota

El sistema debe mostrar:

* promedio general
* porcentaje de aprobados
* estudiante con mayor nota
* estudiante con menor nota

---

# 4. Matriz con lógica

Dada una matriz cuadrada de tamaño N:

* mostrar suma de cada fila
* mostrar suma de cada columna
* mostrar suma de diagonal principal y secundaria
* indicar si la matriz es simétrica

---

# 5. Simulación de menú con operaciones

Crear un menú que permita:

1. Registrar números
2. Mostrar números
3. Calcular promedio
4. Buscar un número
5. Ordenar los números (ascendente)
6. Salir

El programa debe mantener los datos mientras el usuario no salga.

---

# 6. Procesamiento de archivo de texto

Dado un archivo `.txt` con múltiples líneas:

* contar número de líneas
* contar palabras totales
* contar cuántas veces aparece una palabra específica ingresada por el usuario
* mostrar la línea más larga

---

# 7. Archivo binario con registros

Se tiene un archivo binario de clientes con:

* número de cuenta
* nombre
* saldo

El programa debe permitir:

* agregar un nuevo cliente en una posición específica
* modificar el saldo de un cliente
* mostrar todos los clientes

---

# 8. Comparación de estructuras dinámicas

El programa debe:

* almacenar una lista de números
* eliminar los repetidos
* mostrar los valores únicos
* mostrar cuántas veces se repite cada número

---

# 9. Manejo de memoria dinámica

El programa debe:

* pedir una cantidad N
* crear dinámicamente un arreglo
* almacenar valores
* calcular media, mediana y moda

---

# 10. Sistema completo (integrador)

Desarrollar un sistema que permita gestionar productos:

Cada producto tiene:

* código
* nombre
* precio
* cantidad

El sistema debe:

* registrar productos
* mostrar inventario
* calcular valor total del inventario
* buscar productos por código
* guardar información en archivo
* recuperar información desde archivo

---

# 11. Registro de asistencia

Se solicita un programa que permita registrar la asistencia de estudiantes.

Cada registro contiene:

* carné
* nombre
* fecha
* estado (Presente, Ausente, Tarde)

El sistema debe permitir:

* registrar múltiples asistencias
* almacenar la información en un archivo
* leer la información almacenada
* calcular cuántos estudiantes están en cada estado
* buscar la asistencia de un estudiante por su carné

---

# 12. Procesamiento de ventas

Se tiene un archivo de texto con múltiples registros de ventas, donde cada línea contiene:

* código de producto
* nombre
* cantidad vendida
* precio unitario

El programa debe:

* leer el archivo completo
* calcular el total por cada venta
* calcular el total general vendido
* determinar qué producto generó mayor ingreso
* generar un nuevo archivo con un reporte de los resultados

---

# 13. Gestión de empleados en archivo binario

Se requiere un sistema para manejar información de empleados almacenada en un archivo binario.

Cada empleado contiene:

* id
* nombre
* salario
* departamento

El programa debe:

* registrar empleados
* almacenar los registros en archivo binario
* leer todos los empleados
* buscar un empleado por su id
* modificar el salario de un empleado existente
* actualizar el registro directamente en el archivo

---

# 14. Limpieza de archivo de texto

Se tiene un archivo de texto con contenido variado.

El programa debe:

* leer el archivo línea por línea
* convertir todo el texto a minúsculas
* eliminar signos de puntuación
* contar el total de palabras
* generar un nuevo archivo con el texto limpio

---

# 15. Historial de operaciones

Desarrollar un programa tipo calculadora con menú que permita realizar operaciones básicas.

El sistema debe:

* permitir realizar operaciones entre dos números
* guardar cada operación realizada en un archivo
* almacenar la operación en formato legible
* leer el historial completo desde el archivo
* mostrar todas las operaciones realizadas anteriormente
